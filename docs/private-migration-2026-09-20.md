# 校友地图私有试迁移（2026-09-20）

本文记录首次试迁移时的状态；地点选择、主题适配和账号生命周期等后续修补见 [上线前复核](release-review-2026-09-20.md)。

目标由用户确认：现有 SSH 私有测试入口。正式论坛 `web_a`、`web_b` 未安装本插件；旧地图仍提供线上服务，旧库未写入。

## 入口与隔离

- 真实数据只读：`http://127.0.0.1:13000/alumni-map`，沿用 `rsc_preview_admin`。
- 合成数据可编辑：`http://localhost:13001/alumni-map`，沿用 `rsc_alice`。
- 继续使用既有 SSH 转发的 13000、13001 端口；未新增公网入口。
- 两个测试站同处 `rsc-private-preview`，分别使用 `rsc_readiness_snapshot`、`rsc_discourse_smoke`，与正式论坛数据库隔离。RSC 与校友地图共存。
- 真实名片映射到测试站既有的同 ID 占位账号，未复制生产密码、登录凭据或激活真实用户登录。

## 本次修正

- 不再强制旧版无位置/无坐标用户补齐坐标才能保存或取消公开。
- 未更改城市时，修改其他资料不依赖地理编码服务；换城市且没有编码服务时不沿用旧城市坐标。
- 补齐学校、专业、入学/毕业年份、公司、职务、行业、空闲时间和联系方式的展示。
- 年份严格限制为四位数字，拒绝 `2018oops` 等输入。
- 增加 `alumni_map_read_only`：API 拒绝编辑、管理和上传，页面不显示修改表单。
- 地图点可点击查看该点的校友，再跳到对应名片。
- 高德 SDK 放在仅允许脚本、禁止同源访问的沙箱页面中；地图所需的 eval 权限只在该页面开放，论坛主页面 CSP 保持不变。SDK 原有 iframe 尺寸传感器改用其内置的 DOM 传感器，并用 ResizeObserver 补偿窄屏变化，以兼容沙箱和手机宽度。此适配依赖 SDK 2.0 的 `DomUtil.watchSize2`，供应商更新时需要回归验证。

## 验收和后续差异

后端隔离测试：28 项、210 个断言通过；新增地图沙箱后，定向运行 5 项地图测试、50 个断言通过，覆盖名片公开与隐藏、坐标降精度、无位置资料、只读保护、权限、校验和与回滚导入，并检查其他原生插件的共存。

真实导出、导入前的两个数据库备份、逐条核对结果及浏览器验收资料保存在 `/opt/alumni-private-preview`，目录权限 700，数据文件权限 600；不要提交到代码仓库或公开分享。

这是供试用的原生版本，尚未正式切换。旧版国家/省/市联动选择器尚未等价迁入，目前使用城市输入和坐标选填。后续已恢复省/城市聚合、人数光圈和选中区域后展示名片，使用地图下方的区域面板；详见 [底图与区域浏览修正](map-interaction-fix-2026-09-20.md)。私有容器禁止出网，因此不配置服务端高德编码 Key；前端使用旧项目的浏览器 SDK 配置，已在两个私有入口实测底图加载，主页面与沙箱无 CSP 拦截、无 JavaScript 错误，沙箱无法访问论坛 DOM。演示站的编辑、取消公开和用户名显示开关通过浏览器测试，测试后恢复演示资料。地图标记到名片的跳转、1440 → 390 像素的窗口缩放后地图尺寸同步也通过了实际浏览器验收。

正式上线前还需处理用户删除/合并/隐私导出的生命周期、完善上述地点交互，并在正式域名验证高德 SDK 配置及最终增量迁移。管理员隐藏后，用户自行编辑不会自动恢复展示；这比旧版自动清除隐藏的行为更严格，现有快照没有隐藏记录。

技术参考：[高德 JS API 2.0 官方文档](https://a.amap.com/jsapi/static/doc/index.html)。沙箱适配依据本机实际 SDK 的行为和浏览器验证，不能据此视为供应商对沙箱兼容性的保证。
