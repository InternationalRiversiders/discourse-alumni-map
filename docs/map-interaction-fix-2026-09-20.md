# 区域浏览与底图空白修正

用户在 VS Code 内置预览中看到标记但没有底图，并希望恢复旧站的区域选择和人数光圈。

## 行为

- 首页不再展开所有校友名片；点击光圈或“按地区选择”后，仅显示所选区域的名片，可关闭列表。
- 中国区域在缩放小于 7 时按省聚合，放大后按城市聚合；海外沿用旧站按国家／州分组的规则。
- 光圈尺寸和光晕随人数增长，并显示人数与地区名称；提供可点击的放大、缩小按钮。
- 区域统计只纳入已公开且未隐藏的名片；同一区域没有坐标的名片仍可在区域列表查看，不伪造个人坐标。

## 空白底图定位

以启用 WebGL 的 Chromium 重现了截图现象：1 个地图 canvas、0 张底图瓦片，标记可见，底图为空。之前验收恰好落到 SDK 的图片瓦片路径，没覆盖这一差异。SDK 的 `complete` 事件不足以证明底图已经绘制。

当前在不改变论坛 CSP、继续保持地图沙箱隔离的前提下，统一使用 SDK 2.0 的二维图片瓦片渲染。仅当至少 2 张可见底图瓦片完成解码时标记加载成功；超时显示明确提示，提供重新加载和地区选择备用入口。

实现使用当前 SDK 中实际存在的 `forbidenWebGL`、`forceWebGL`、`forceWebGLBaseRender` 渲染开关。这些属于 SDK 实现细节，后续供应商升级需要回归；浏览器测试特意提供可用 WebGL，并验证最终使用图片瓦片、沙箱隔离和实际瓦片加载，避免再次仅凭标记判断成功。

## 验证记录

- 6 项地图后端测试、56 个断言通过，覆盖分组、归属、公开／隐藏、无坐标、只读和沙箱访问限制。
- 浏览器覆盖初始无名片、点击区域后的 ID 集合一致性、人数与光圈大小、缩放到城市、手机宽度变化。
- 普通页面和嵌入页面均在 WebGL 可用的环境中解码了 15 张真实瓦片，使用二维图片渲染，无 JavaScript 错误。
- 人为阻断瓦片后未误报加载成功；地区列表仍可浏览，恢复网络后点击“重新加载地图”（重新载入当前页面）成功恢复。
- 网络失败／重试和嵌入场景结果保存在私有目录 `/opt/alumni-private-preview/regions-browser-report.json`。
- 正式论坛和旧地图均未切换；真实名片数据没有修改。

SDK 图层背景参见[高德官方图层文档](https://developer.amap.com/api/javascript-api-v2/guide/layers/official-layers)。本次故障定位和修复结论来自本机复现与浏览器验证。
