# 校友地图上线前复核（2026-09-20）

复核对象：`/opt/alumni-map` 旧版与 `discourse-alumni-map` 原生插件。此次更新部署到现有私有测试入口；生产 `web_a`、`web_b` 和旧站仍未切换。本文接续此前的迁移和底图修复记录。

## 功能对照与修补

| 项目 | 旧版 / 发现的差异 | 此次结果 |
| --- | --- | --- |
| 配色 | 旧版地图固定深色，新版此前固定浅色 | 根据 Discourse 实际 `--scheme-type` 自动适配，响应论坛手动模式、系统自动模式及配色样式表切换；保留地图位置和选区 |
| 底图兼容 | VS Code 嵌入预览的 WebGL 路径曾空白 | 保留已验证的 SDK 2.0 栅格渲染与不允许同源的沙箱，只调整底图图片的深色配色；人数光圈、按钮、版权信息分别适配。传入高德沙箱的数据只包含地区中心、人数和选区编号，不传名片昵称、用户编号或名片详情 |
| 区域浏览 | 初版一次展示所有名片 | 保留点击省 / 城市后才展示名片；人数越多光圈越大；收起名片与下方区域选择也同步地图选中状态 |
| 地点编辑 | 初版手填城市和坐标 | 恢复旧版 111 个国家 / 地区、省州、城市联动选项；用户无需输入经纬度；保留旧记录不在目录中的名称 |
| 地点解析 | 换城市缺坐标、服务故障可能阻塞保存 | 海外城市用旧目录坐标；27 个旧版预置城市可离线解析，其他国内城市由服务端高德查询；失败保存文字位置并提示，不借用旧城市坐标 |
| 位置选填 | 无位置旧名片编辑、取消公开容易被校验阻塞 | 支持不填写或清除位置，无坐标名片仍可通过地区选择查看；精度仍为四分之一经纬度 |
| 名片资料 | 部分字段缺失、标签含义不准 | 全部 10 个旧资料字段保留，恢复“学院 / 公司机构 / 职位方向 / 联系偏好”等含义；前端长度限制与后端一致 |
| 论坛账号 | 新版仅展示用户名文字 | 选择公开用户名才提供原生 `/u/用户名` 链接及用户卡片；未公开时不给前端用户名和链接 |
| 统计 | 旧版有人数、省份、国家数 | 恢复公开名片、国内省份、国家 / 地区统计，排除空值 |
| 搜索与数量 | 地图最多 500 人，管理页只取 100 条；空搜索无提示 | 取消公开地图的静默截断；管理每页 50 条，可搜索昵称、账号、地区；补齐无结果提示 |
| 管理名片 | 初版管理缺少账号、公开状态、原因 | 管理员可见归属账号、公开 / 私有 / 隐藏状态、处理原因；分页可访问全部资料 |
| 隐藏与恢复 | 旧版编辑会自动清除隐藏 | 保留“管理员隐藏不能由用户自行编辑解除”的改进；隐藏后撤回公开，解除隐藏后由本人重新选择公开，避免管理员代为发布 |
| 注销 / 匿名化 | 独立旧站不会跟随论坛账号变化 | 通过论坛原生事件清理名片、所属导入归档、通知及命令；插件设置停用时仍清理已存数据 |
| 合并账号 | 初版未处理一人一名片的唯一约束 | 无冲突时归并到目标账号并设为不公开；两边都有名片时保留目标账号名片，清理来源副本，不自动拼接资料 |
| 个人数据下载 | 未实现 | “我的名片”可下载本人的当前资料和旧导入资料，不能通过传其他用户 ID 导出别人；这是插件独立下载入口，不是扩展论坛总归档包 |
| 无关接口 | 共享脚手架遗留上传入口 | 移除本插件不使用的上传与媒体路由，避免提供没有用途的存储接口 |

保留的有意差异：使用论坛原生账号、权限和通知，不保留独立 SSO / 旧站管理员密码；年份严格校验，不接受 `2018oops`；名片在地图下方按选区展示，放大后保持城市聚合，不恢复旧侧栏逐人抽屉；保存后留在“我的名片”并显示结果，方便确认。论坛管理员始终拥有插件管理权限，可配置其他管理组。

地区选项复用旧项目实际安装的 `country-state-city 3.2.1`、`china-area-data 5.0.1` 及旧国家中文名称、预置城市。离线文件由 `script/build_locations.cjs` 生成，许可证放在 `data/locations`；不依赖运行 Node 服务。地区目录可能不包含近期行政区划变更，与旧版一致；已导入名称不会因此丢失。

## 数据与配置复核

此次再次只读导出旧站，与前次逐条核对：953 个旧账号、161 张名片均无新增、删除或字段变化。私有真实快照仍为 123 张公开、38 张未公开，其中 116 张公开名片有坐标、7 张无坐标。没有为了补地图点而猜测或改写真实用户的位置。

原有服务端高德 Key 已从当前服务器对公开城市“河北石家庄”执行只读查询，返回 `status=1 / OK` 且有坐标。私有论坛容器禁止出网，仍不配置服务端 Key；使用离线目录验证地点编辑。正式论坛域名下的浏览器 Key 白名单与嵌入式渲染仍应在实际切换时验收。密钥、真实导出和测试截图仅存放于权限受限的 `/opt/alumni-private-preview`。

## 正式切换步骤

1. 固定本次验收的插件版本（当前本地仓库尚无远程仓库），按论坛原生插件方式放入构建来源。备份生产论坛数据库、旧站数据库与部署配置。`web_a` 与 `web_b` 共用数据库：两边和 Sidekiq 都必须包含同一插件版本，不能将其中一个当隔离测试库。
2. 先保持 `alumni_map_enabled=false`，部署代码、迁移插件表、编译资源。确认目标插件表为空。当前导入器仅支持空目标首次导入与同一 SHA 文件的幂等重跑，**不支持往已有测试数据上覆盖或增量合并**。
3. 到切换窗口时暂停旧地图的写入，再只读导出最终文件，按稳定论坛用户 ID 核验归属，校验 SHA256。使用 `script/import_legacy.rb` 先事务回滚演练，再传 `RIVER_IMPORT_APPLY=1` 与匹配的 `RIVER_IMPORT_SHA256` 导入。不要直接用测试快照替代最终导出。
4. 使用 `bundle exec rails runner plugins/discourse-alumni-map/script/verify_legacy.rb /安全目录/最终导出.json` 只读核对每条资料、归属、公开状态、隐藏状态、位置、10 个资料字段与时间；公开未发布数量、无坐标数量应与最终导出一致。确认没有导入历史通知，RSC 数据不变。
5. 设置校友访问组 `verified_uestcer`、`zjuer`；按旧权限配置管理组 `管理人员`、`管理员`、`rs_developer`（使用生产组 ID，不能复制测试组 ID）。配置浏览器 Key / security code / 服务端 Key，真实上线关闭 `alumni_map_read_only`。
6. 启用后用普通校友、非校友与管理员验证访问、本人编辑和撤回公开、国内外地点、深浅色、人数光圈、管理操作及原生通知，再切换旧地图入口。保留旧站只读备份；避免新旧同时写入。

回退：如果新站尚未接受写入，可以关闭插件、恢复旧入口和旧站写入。如果新站已经接受编辑，先冻结新写入并导出插件资料，核对合并这些变化后再恢复旧站；不能直接回滚整库而丢失期间论坛/RSC数据。

## 验证记录

隔离后端定向测试：13 项、110 个断言通过。覆盖导入 SHA / 回滚 / 幂等、公开权限、只读保护、地图沙箱、501 人以上列表、管理分页搜索、国内外城市解析、清空位置、查询失败时撤回公开、账号真实合并 / 匿名化 / 删除、个人导出与地区接口鉴权。

浏览器验收：普通页面与模拟 VS Code 的嵌入式 Chromium，均验证 GPU 可用但地图实际使用栅格图块，15 张可解码底图、沙箱隔离、人数光圈、点击选区、城市缩放、390 像素宽度同步，无 JavaScript 错误。深色模式下新加载的图块也完成着色。强制阻断图块时显示失败提示，地区选择仍可用；解除阻断并重试后恢复。这里未声称直接自动操作了用户的 VS Code 应用本身。

另外实际操作论坛的浅色 / 深色 / 自动模式，验证强制浅色优先于系统深色、自动跟随系统，地图与选区保留。演示用户通过联动选择“美国 → California → San Francisco”，保存并刷新后坐标与城市保持一致；手机表单无横向溢出，个人导出为仅本人的附件，空搜索有提示。全部浏览器用例未出现 JavaScript 错误，合成名片已恢复原值。

真实快照通过 `script/verify_legacy.rb` 逐字段核验：953 个旧账号、161 张名片、123 张公开、116 张公开有坐标，命令数与事件数均为 0。插件资源编译通过，`git diff --check` 通过。
