# Legacy location catalog

Generated by `node script/build_locations.cjs /path/to/legacy-alumni-map`.

Sources: the legacy project's `lib/countries.ts`, `lib/locations.ts`, installed `country-state-city` 3.2.1 (GPL-3.0; bundled license), and `china-area-data` 5.0.1 (MIT; bundled license). These are public place names and city coordinates, **not alumni profile data**.

Country codes are allowlisted from `countries.json` before reading a country file. The authenticated Rails API serves only requested states/cities. Coordinates are rounded before storing a profile; China cities not present in the known-city fallback use the configured server-side AMap geocoder.

Regeneration should retain the versions above unless a separate catalog update is reviewed and tested. Keep the accompanying licenses with redistribution.
