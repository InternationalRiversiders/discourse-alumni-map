# 校友地图

Discourse 原生插件，使用论坛 PostgreSQL、登录与用户组授权，无需独立服务。安装后运行数据库迁移、构建插件资源，并确认 Sidekiq 正常运行。

## 访问与隐私

- `/alumni-map` 展示地图，地区被点击后才分页读取名片，每页 30 张。
- 名片按内容高度自动排列；手机单列显示，用户名在头像旁优先展示，长名称省略，未填写资料不保留空白区域。
- 名片接口重新检查公开状态、搜索条件与用户权限；隐藏或撤回的资料不通过旧地图数据泄露。
- 论坛用户名与头像仅在作者勾选公开用户名时展示；地图 SDK 只接收地区汇总。
- 城市解析在保存事务外准备，锁内检查版本，避免网络请求长期占用数据库锁或覆盖并发编辑。
- `alumni_map_read_only` 阻止写入和通知投递。用户删除、匿名化和合并会清理或迁移对应资料。

## 后台通知

保存成功后唤醒 Sidekiq 投递，排队故障不改变保存结果，每分钟定时任务补偿扫描。逐条加锁并在同一事务保存通知和完成状态；异常退避重试，不阻塞其他收件人。停用、只读或收件人失去权限时不投递。

## 验证与历史资料

`test/regression_test.rb` 和 `test/notifications_test.rb` 是本插件的版本化验收入口，仅允许 `RIVER_DISPOSABLE=1` 且数据库名为 `river_community_test` 的隔离环境，运行会清空本插件测试表。覆盖权限、账号生命周期、地图地区、懒加载、分页、公开设置、并发编辑与通知重试。

旧系统导入工具及历史验收记录位于 `script/`、`docs/`，不是线上数据清单；当前名片、权限与配置以论坛数据库为准。
